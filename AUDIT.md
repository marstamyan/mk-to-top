# Проверка MK To Top Button

Дата: 14 ноября 2026 года. Исходный репозиторий: <https://github.com/marstamyan/mk-to-top>, исходный коммит `50b2102`. Подготовлена версия **1.1.0**.

## Оценка

Для небольшой кнопки возврата наверх выбран подходящий объём функциональности: размеры, цвета, сторона, отступ, порог прокрутки и отображение на мобильных. Переписывать плагин с нуля или добавлять тяжёлые зависимости не потребовалось. В исходной реализации были реальные ошибки в настройках, доступности и очистке данных.

Подтверждённого обхода прав доступа или XSS не обнаружено. Исходная форма уже использовала штатный Settings API и экранирование HTML. Это результат проверки данного кода и перечисленных сценариев, а не гарантия отсутствия любых уязвимостей.

## Найдено и исправлено

| Проблема исходной версии | Исправление |
| --- | --- |
| При первом сохранении отключение мобильной кнопки могло снова включиться: повторная обработка `'0'` давала `'1'`. | Флажок проверяется по значению; повторная обработка сохраняет результат. Проверено на настоящем первом сохранении через `options.php`. |
| Отсутствующий `btn_position` вызывал предупреждение PHP; массив вместо цвета вызывал `TypeError` на PHP 8. | Общая проверка типов и значений при сохранении и чтении; повреждённые настройки получают допустимые значения без предупреждений. |
| Ограничения размеров, отступов и порога были только в HTML. В БД проходили нули для размеров, чрезмерные числа; отрицательные превращались в положительные. | Ограничения применяются на сервере: размеры 20–200, отступ 0–500, порог 0–5000. Числа за пределами диапазона ограничиваются; неверные типы заменяются значениями по умолчанию. |
| Проверка цвета принимала `rgb(999,999,999)`, `rgba()` без прозрачности и `rgb()` с лишним компонентом. | Проверяются число компонентов, RGB 0–255 и прозрачность 0–1. Корректные старые HEX/RGB/RGBA сохранены. |
| Невидимая кнопка оставалась в клавиатурной навигации; индикатор фокуса был отключён. | Скрытие синхронизирует `hidden`, `tabindex` и `aria-hidden`; добавлена видимая обводка фокуса. Указан `type="button"`. |
| Плавная прокрутка игнорировала предпочтение уменьшения анимации. | При `prefers-reduced-motion` используется мгновенная прокрутка; анимация прозрачности отключается. |
| Поздняя загрузка скрипта могла пропустить `DOMContentLoaded`. | Скрипт учитывает готовность документа и восстановление страницы из истории; повторное подключение не дублирует обработчики. |
| Обработчики выполняли работу на каждом событии прокрутки. | Обновления объединены через `requestAnimationFrame`, обработчик прокрутки пассивный. |
| Инструкция обещала `Settings > MK To Top`, но плагин создавал отдельный пункт меню; поля не имели связанных подписей. | Страница перенесена в Settings, подписи связаны с полями, радиокнопки объединены в группу. |
| Динамические строки мешали извлечению переводов; название кнопки не переводилось; версии административных файлов были зафиксированы как `1.0`. | Строки подготовлены к переводу, ресурсы используют общую версию плагина. Готовые переводы в эту версию не добавлялись. |
| Селектор административного CSS мог затрагивать чужие таблицы. | Стили ограничены областью настроек плагина; улучшены ширина полей и расположение переключателей. |
| Удаление плагина в Multisite очищало только текущий сайт. | Настройки удаляются на всех сайтах порциями по 100 ID; прочие настройки сохраняются. |

В процессе браузерной проверки также исправлено повторное уведомление об успешном сохранении после переноса страницы в Settings.

## Проверки

- PHP 7.4 и 8.0: проверка синтаксиса и оба набора PHP-тестов проходят.
- PHP 8.3.36: оба набора PHP-тестов проходят — 257 проверок настроек/HTML и 850 проверок удаления, включая модель сети из 205 сайтов. Это проверки с небольшими заменами WordPress API.
- Node.js: 15 тестов поведения JavaScript проходят, включая границы мобильного режима, восстановление страницы и повторную загрузку скрипта.
- Настоящий WordPress 7.1.4 с PHP 8.3.36, MariaDB 10.11.19 и темой Twenty Twenty-Five 1.5: 10 интеграционных проверок сохранения настроек и вывода кнопки проходят.
- Microsoft Edge: 13 браузерных сценариев проходят. Проверены настоящие сохранения через админку, первое снятие мобильного флажка, сохранение цветов и размеров, порог 120/121 px, клавиши Enter/Space, видимый фокус, ширины 390/768/769 px, изменение размера окна, уменьшение анимации и отключённый JavaScript. Неожиданных ошибок JavaScript не обнаружено.
- Защита формы: неверный защитный код и попытка сохранения от подписчика возвращают HTTP 403 и не меняют настройки. Административные файлы плагина не загружаются на посторонних страницах.
- Настоящее удаление настроек проверено на одиночном сайте и в сети из трёх сайтов WordPress: опция плагина удалена везде, посторонние контрольные опции сохранены. Активация и деактивация для всей сети проходят. В тесте использован штатный обработчик удаления с `--skip-delete`, чтобы сохранить подключённые исходники.
- При включённом `WP_DEBUG` журнал с ошибками плагина не создавался.
- Установочный ZIP собран с корневой папкой `mk-to-top`; временная среда, тесты и служебные файлы в него не входят.

Автоматические проверки находятся в `tests/`; команды повторного запуска — в `README.md`. Локальные браузерные результаты и снимки экрана находятся в исключённой из Git папке `.local-test/`.

После проверок временные контейнеры и две тестовые базы/тома удалены. Другие сайты и контейнеры не изменялись.

## Что учесть при установке

- Ключ БД `mk_to_top_options` и существующие настройки сохранены. Недопустимые старые значения теперь ограничиваются или заменяются значениями по умолчанию.
- Исходная адаптивная формула размеров сохранена и описана в настройках: базовое значение 40 px даёт диапазон 30–50 px. Настройка отступа применяется и снизу, и с выбранной стороны.
- Настройки теперь находятся в `Settings > MK To Top`. При деактивации они остаются; при удалении плагина очищаются.
- Полный запуск проверен на указанной версии WordPress и в Edge. Совместимость со всеми темами, плагинами, Safari/Firefox и полная проверка WordPress 6.0 не выполнялись. Синтаксис PHP 7.4 проверен, но для рабочего сайта следует выбирать поддерживаемую версию PHP.
- Тема должна вызывать стандартные `wp_head()` и `wp_footer()`. Для работы кнопки нужен JavaScript.
